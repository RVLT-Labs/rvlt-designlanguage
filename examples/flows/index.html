Reference compositions

Whole tasks, not isolated widgets: what the crew sees, what was saved, what is still pending and the next safe action. Each composition is built from the @rvlt/flow-theme registry, compiled with preview-v2. Browser regressions cover 320, 390 and 768px and desktop in both themes; consult the remediation matrix for actual run results.

What these are, honestly: front-end reference compositions with simulated data. There is no backend, no real sync and no scanner, and no user testing is claimed. Timed tasks with crews on the dock and stage managers in the prompt corner are still to be run.
