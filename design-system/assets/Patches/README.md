# Patches

There are 7 shaped word patches: Standby, Go!, Crew, Load in, On air, Show time and RVLT Flow. Each includes its backing, a 4-unit cream edge and a hard shadow, and each has its own cropped viewBox.

Size each one by eye at 160–320px wide. Don't force them into the same box. The patches are decorative phrases, so real status, loading and live state stay in the UI. The RVLT Flow patch is an expressive lockup, not the master logo.
