# Stickers

There are 19 illustrated gear stickers, each a 128 × 128 SVG. Every one includes its colour backing (a circle or a rounded square), a 3-unit cream `#FFFDF8` edge and a hard `#0C0A08` shadow offset 2,4. They work on any ground. Don't add a CSS shadow, border or tint.

Show them at 96–240px (160px default) with a 2–5° tilt applied once. Use `alt=""` when the art is decorative. Use them for marketing clusters and for single app moments (welcome, onboarding, empty, success), never on data screens.
