# Linework

These are the 19 illustrations as transparent line drawings in cream `#FFFDF8`, with a 3.4-unit round stroke and no backing. Use them only on espresso or another dark surface, because they vanish on Paper. They are a quieter accent than the stickers, shown at about 96px.

Parent CSS `color` can't recolour them. A recoloured variant is a separately reviewed file.
