# Albert

Albert is RVLT's character: a bearded dragon in amber, cream `#FFFDF8`, espresso, coral and RVLT red. These are the 23 coloured SVGs from his static pack. He is always filled in.

| File | Use |
|---|---|
| `albert-icon.svg` / `albert-icon-cream.svg` | Chat buttons, tiny avatars and inline UI at 24–48px. Use `icon` on light grounds and `icon-cream` on dark. |
| `albert-avatar.svg` | The fuller coloured head, at 64px or larger. Also the assistant's "ready" state. |
| `albert-expression-*.svg` | Assistant states at 64px or larger: listening → `listening`, processing → `thinking`, clarification → `puzzled`, success → `content` or `happy`, recovery → `reassuring`. `catch`, `blep` and `wink` are occasional playful choices. Always put the state in live text as well. |
| `albert-sticker-amber.svg` / `albert-sticker-red.svg` | Decorative stickers, 96px or larger |
| `albert-head-line-espresso.svg` | The one monochrome drawing. Light grounds only. |
| `albert-sitting.svg`, `albert-seated-on-case.svg`, `albert-master.svg`, `albert-peek.svg`, `albert-happy.svg` | Scalable full-body derivatives. For review, prefer the locked PNGs in `Albert-illustrations`. |

Never use uncoloured full-body line art, a humanoid redraw, detached props, recoloured pixels or a novelty cursor.
