# Albert

RVLT's character — a filled-in bearded dragon — placed as a plain image: an assistant state, a welcome or empty-state illustration, or a sticker.

## Usage
- Assistant states use the coloured expression SVGs at 64px+ (ready → avatar, listening, thinking, puzzled, content/happy, reassuring) with the state always written in live text beside him.
- Small marks (24–48px): `albert-icon` on light grounds, `albert-icon-cream` on dark.
- Welcome, headers and large empty states use a locked illustration (`sitting`, `on-the-case`, `rest`); topic screens use the workday illustration mapped to them (see the Albert-illustrations group).
- Set width only; preserve aspect ratio and transparency. Meaningful alt text when he carries context, `alt=""` when decorative.

## Don't
Redraw, recolour, outline, detach props, stack PNGs, crop into him, shrink a full-body illustration into a 24–48px control, or use him in alerts, compliance, conflict or destructive messages.
