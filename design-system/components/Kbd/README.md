# Kbd

A key cap shown next to the action it triggers: Geist Mono 11px on `paper-2` with a 1px `line-2` border and a 2px bottom edge — one spec in every RVLT product (decision 2026-10-19).

Radius 5px, 6px side padding, `muted` text. Binder shows the shortcuts people forget in its status bar (`c` `]` `g` `⌘K`) and in tool corners; Flow shows them in tooltips and the `?` shortcuts dialog.


_Live: the real component, compiled into `bundle.js` from TwoToned/gearflow@5a85e40 `src/components/ui/kbd.tsx`, which now draws Binder's key cap at 11px (decision 2026-10-19). RVLT-Labs/binder `apps/web/src/components/ui/kbd.tsx` matches it._
