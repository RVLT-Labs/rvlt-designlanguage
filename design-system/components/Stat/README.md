# Stat

A figure in Archivo extra-bold over a faint label; exactly one per group is the bright hero.

- `bright` — 38px `ink` (`stat-hero`). One per group.
- default — 24px `ink-2` (`stat`).
- Label — 12px `faint`.

Figures are tabular. Write concrete numbers ("0 double-bookings", "99.9% accounted for"), never vague claims. Dashboards use a bento grid of individually bordered tiles, at most 4 per row.

## Consumer provides
`figure` (number or short string), `label`, optional `bright`.
