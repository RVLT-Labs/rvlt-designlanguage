# BinderEmptyState

Binder's empty list: a left-aligned card with an optional icon tile, a plain heading, one line of what to do, an optional Kalam line and one outlined action.

`card` fill, 2px `line-2` border, `r` corners, `sh-card`, 18px padding. Icon tile 36px, `r-btn`, `elev`, `muted` 18px icon. Heading 15px / 600 `ink`; body 13.5px / 1.5 `ink-2`; Kalam 18px `ink-2` — never red, and the only place Kalam appears in a list.

Differs from Flow's centred, mascot-led EmptyState: Binder has no mascot; its personality is the Kalam line.

_Live: the real component, compiled into `bundle.js` from RVLT-Labs/binder@f822fdb `apps/web/src/components/EmptyState.tsx`._
