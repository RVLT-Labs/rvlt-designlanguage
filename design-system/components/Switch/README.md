# Switch

A 44×24 pill toggle for settings that apply immediately; on = solid `red` track with a white thumb.

Off: 2px `border` outline on `paper-2`, `ink` thumb at 2px. On: thumb slides 20px. Use for instant settings; use Checkbox inside forms that submit.

## Consumer provides
A visible label, `checked` / `onCheckedChange` (Radix).

_Published Flow preview: local registry source, compiled by `scripts/design-system/bundle/build-registry.mjs`. The pinned external bundle is retained for Binder adapters._
