# Skeleton

A solid `elev` block that pulses while content loads — no gradient shimmer.

`r-sm` radius by default; circles for avatars. Match the real layout's shapes (TableSkeleton, CardSkeleton). Pulse only when motion is allowed. Show for at least 200ms to avoid a flash.

_Published Flow preview: local registry source, compiled by `scripts/design-system/bundle/build-registry.mjs`. The pinned external bundle is retained for Binder adapters._
