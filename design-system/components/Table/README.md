# Table

The data table: 13.5px rows separated by 1px `line` rules, hover and selection on `elev`.

Heads: semibold `ink-2`, left aligned, 8px × 12px. Cells: `ink-2`, 8px × 12px. Footer: `paper-2`, top `line`. Caption: 12px `muted` below.

## Content rules
- IDs and asset tags in `t-mono` (Geist Mono, `muted`).
- Money and counts right-aligned, tabular, medium weight.
- Status as a StatusIndicator dot with its label, or a Badge.
- Full width — tables escape the 1080px content max.
- Phones: keep the semantic table in a labelled scroll region or switch to a labelled card list; never hide required columns silently.

_Published Flow preview: local registry source, compiled by `scripts/design-system/bundle/build-registry.mjs`. The pinned external bundle is retained for Binder adapters._
