# EmptyState

Flow's zero-data block: Flow the mascot, one operator-voice line, optional action — the sanctioned home for personality.

20px radius, 2px `border` outline, 28px padding, centred. Mascot 48px in `muted`. Title 14px medium `ink-2`; description 12px `faint`. The action is usually a `line` Button.

Binder uses a left-aligned card without the mascot (see BinderEmptyState).

## Copy
Domain-specific and dry: "Nothing booked yet — Flow's having a quiet one.", "No clashes. Suspiciously calm.", "No assets checked out". Never "No results found".

## Don't
Never use the mascot, jokes or Kalam in alerts, overdue states, compliance failures, conflicts or destructive confirmations — those get plain, direct copy.
