# SectionHeader

The calm section label: `t-overline` (11px semibold, sentence case) in `muted` — the everyday divider.

`SidebarSection` wraps one in a block with a bottom `border` rule and 16px padding, for the right-hand key-facts column of detail pages. The red Kalam "prominent" label is for marketing and hero moments only.

## Don't
Never uppercase. On mobile, section headers drop the extending rule.
