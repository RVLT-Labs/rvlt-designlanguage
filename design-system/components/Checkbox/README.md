# Checkbox

A 20px square checkbox with `r-sm` corners; checked fills solid `red` with a white 3px-stroke check.

Unchecked: 2px `border` outline on `paper-2`. Focus ring and 45% disabled as standard. On touch devices the hit area grows to 24px minimum.

## Consumer provides
A label beside it, `checked` / `onCheckedChange` (Radix).

_Published Flow preview: local registry source, compiled by `scripts/design-system/bundle/build-registry.mjs`. The pinned external bundle is retained for Binder adapters._
