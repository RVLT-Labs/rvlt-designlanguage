# PulseLockup

Pulse's header lockup: the five-bar glyph on an RVLT-red tile, "Pulse" in Archivo 800 and a "by RVLT" pill that holds the unaltered RVLT mark. The real `PulseLockup` from `@rvlt/pulse-ui/brand`, used by both Live and Manager. The second lockup adds Manager's suffix.

## Rules
- The tile is `cream` bars on `red`, radius 22.6%, built like Binder's and Flow's app icons (`assets/Logos/pulse-mark.svg`).
- "by RVLT" is a 1px `line-2` pill. The RVLT outlines are never retyped, recoloured beyond `red`, or redrawn.
- The bars are the brand mark only. They are never reused as an interface glyph.

_Live component from `qubered/a2-monitor` `packages/ui/brand/PulseLockup.tsx` at the commit recorded in `pulse-bundle.js`._
