# Stickers & Wordmarks — pack 1.1.0 (2026-09-25)

The RVLT Flow sticker and wordmark collection, copied unchanged from the handoff pack. Rules for using it: `DESIGN.md` §10.

| Path | What |
|---|---|
| `svg/*-sticker.svg` | 19 illustrations with colour backing, cream edge and hard shadow |
| `svg/*-line.svg` | the same 19 as transparent cream line drawings (dark grounds only) |
| `svg/*-patch.svg` | 7 word patches: Standby, Go!, Crew, Load in, On air, Show time, RVLT Flow |
| `svg/*-wordmark.svg` | the same 7 as transparent lettering (dark grounds only) |
| `manifest.json` | IDs, variants, viewBoxes, display widths, gallery tilts, SHA-256 of each SVG |
| `palette.json` | artwork colours (not app status tokens) |
| `STYLE-GUIDE.md`, `IMPLEMENTATION.md`, `ASSET-CATALOG.md`, `COLLECTION-UPDATES.md`, `PRINT-AND-EXPORT.md`, `CREDITS.md` | the pack's own docs; their `assets/svg/…` paths are `svg/…` here |
| `licenses/` | Phosphor MIT + Archivo/Baloo 2 OFL — ship them with any copy |
| `PACK-README.md` | the pack's original README |

The pack's `CHECKSUMS.sha256` is not copied (it covers the original folder layout); `manifest.json` still carries every SVG's SHA-256. The illustrated Word guide, preview page and React example stay in the original pack.
