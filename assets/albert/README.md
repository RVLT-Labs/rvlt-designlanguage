# Albert — RVLT's character (static pack, 2026-09-22)

Albert the bearded dragon, copied unchanged from the static asset pack. Rules for using him: `DESIGN.md` §11; the pack's own guide is `PACK-README.md`.

| Path | What |
|---|---|
| `svg/` | all 23 coloured SVGs: icon (light + cream), avatar, head line drawing, 14 expressions, amber and red stickers, peek, happy, sitting, seated-on-case, master |
| `illustrations/` | the three **locked** identity PNGs — sitting, on the roadcase, resting (SHA-256 pinned in `Design-lock.json`) |
| `asset-manifest.json` | every pack file with status, intended use, size and digest |
| `Design-lock.json`, `palette.json` | the approved identity and palette |

Not in git (~25 MB): the 6 pose studies and 22 workday illustrations (`illustrations/albert-core-*`, `albert-work-*`, and the later poses) and the PNG exports of the SVGs. They stay in the original pack and the RVLT design-system artifact; `asset-manifest.json` lists them.
